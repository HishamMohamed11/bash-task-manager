# 🗂️ Mini Task Manager - Bash Project

A complete Task Management System built using pure Bash scripting.

This project demonstrates strong command-line scripting skills including:
- File handling
- Text processing (awk, sed, grep)
- Input validation
- Date comparison
- Modular scripting
- Interactive CLI menus

---

## 📌 Project Overview

The Mini Task Manager is a terminal-based application that allows users to manage daily tasks efficiently using an interactive menu.

All tasks are stored persistently in a text file using a structured delimiter format.

---

## 🛠️ Technologies Used

- Bash Scripting
- awk
- sed
- grep
- date command
- ANSI escape codes (for colored output)
